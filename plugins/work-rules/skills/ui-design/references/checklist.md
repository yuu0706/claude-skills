# 提出前の点検

UI を作った・直した後、提出する前に全項目に「はい／いいえ」で答える。
「いいえ」が1つでもあれば直してから提出する。直さない項目は、理由を報告に書く。
番号は SKILL.md の節に対応する。

## 1. 着手前の決定

- [ ] 「誰が何をしに来るか」「主要な操作」「一覧・詳細・入力のどれか」の3行を、実装の前に書いたか
- [ ] 主要な操作は2つ以下か

## 2. 構造と配置

- [ ] 幅 1280 と 390 のスクリーンショットで、主要な操作がスクロール前に見えているか
- [ ] 主要な操作は、見出し行の右端か、画面下に固定した操作バーのどちらか1か所にあるか
- [ ] 主要な操作が本文の末尾だけに置かれていないか（いないなら「はい」）
- [ ] 削除などの破壊的な操作は、主要な操作と隣り合っていないか（いないなら「はい」）
- [ ] 一覧は表、詳細は2列、入力は1列になっているか
- [ ] ナビは左か上の1か所だけか

## 3. 文字だけで説明していないか

- [ ] ページの見出しは「何の画面か」（対象）を示しているか。プロジェクト名だけの見出しになっていないか
- [ ] 状態は色とバッジで示し、文で説明していないか
- [ ] 説明文は、操作しても分からない箇所の1行だけか
- [ ] アイコンは線の SVG（Lucide など）で、絵文字を使っていないか
- [ ] アイコンだけのボタンに `aria-label` があるか

## 4. 密度・余白・文字

- [ ] 業務画面の本文は 14px、表のセルは 13px、表の行の高さは 36px か（一般利用者向けは1段広げたか）
- [ ] 見出しの大きさは2段階までか
- [ ] 文章の1行の幅は `--measure`（70ch）以内か
- [ ] 業務画面で、1280 の幅に余白ばかりが目立つ箇所が無いか

## 5. AI っぽさ

- [ ] グラデーションの背景・ヒーロー画像・装飾の図形が無いか
- [ ] 角丸のカードを入れ子にしていないか。一覧をカードで並べていないか
- [ ] 影は浮いている面（メニュー・ダイアログ・引き出し）だけに付いているか
- [ ] 紫系の色を既定色として使っていないか
- [ ] 中央寄せの説明文・Lorem ipsum・使わない機能のボタンが無いか
- [ ] 動きは状態の変化を伝えるものだけか（読み込み時の飾りの動きが無いか）

## 6. トークン

- [ ] 色・余白・文字サイズ・角丸・影・z-index を直書きしていないか（`grep -nE '#[0-9a-fA-F]{3,8}|[0-9]+px|z-index: *[0-9]'` で部品の CSS に当たりが無いか。枠線の 1px・フォーカスの輪の 2px・`@media` の境目は除く）
- [ ] 既存のテーマ定義があるプロジェクトで、本 Skill のトークンを持ち込んでいないか
- [ ] 新しい UI ライブラリを足していないか
- [ ] ライトとダークの両方で文字が読めるか

## 7. 状態

- [ ] 空・読込・エラー・無効・成功の5状態を、それぞれ画面で出して確かめたか
- [ ] 空状態に次の操作のボタンかリンクがあるか
- [ ] 読込とエラーで見出し行と操作が消えていないか
- [ ] エラーのときに入力済みの内容が残るか

## 8. 拡張性

- [ ] 1つの変数・定数に意味が1つだけか（表示の上限・利用者の控え・実測値を共有していないか）
- [ ] 描画後の実測値を、利用者の控え（localStorage など）に書いていないか
- [ ] 開閉の状態は `<html>` の data 属性など1か所に集まっているか。機能ごとに写しを持っていないか
- [ ] z-index は層の変数だけを使っているか
- [ ] 詳細度を上げる指定・`!important` を足していないか。勝ち負けを `@layer` か読み込み順で決めたか
- [ ] ライブラリの既定を上書きした箇所に、元の既定値と上書きの理由をコメントで書いたか
- [ ] 既存の指定を変えた箇所で、その指定が支えていた副作用を確かめたか
- [ ] 検査が落ちたとき、検査の範囲を絞って通していないか
- [ ] 画面幅の境目を JS と CSS に直書きしていないか
- [ ] 新しい面・列・引き出しを足したとき、他の開閉状態との組み合わせをすべて撮ったか

## 9. スクリーンショット（Skill `chrome-check`）

- [ ] 幅 1280 と 390 の2枚を撮ったか
- [ ] 開閉状態（メニュー・引き出し・面）の組み合わせごとに撮ったか
- [ ] ライトとダークの両方を撮ったか
- [ ] JS の例外と console.error が0件か
